# 📦 Archives Resizer

Утилита для разделения больших архивов на части размером до 1,6 ГБ для удобной отправки через Telegram.

## 📂 Как распаковать архив из нескольких частей

1. Скачайте **все части** архива (`.part1`, `.part2`, `.part3` и т. д.).
2. Поместите их **в одну папку**.
3. Откройте файл `.part1` с помощью **7-Zip**.
4. Распакуйте архив.

⚠️ **Важно:** все части обязательны. Если 7-Zip не может извлечь файлы напрямую, сначала объедините части в исходный архив.

🔗 **Скачать 7-Zip:** https://www.7-zip.org/
